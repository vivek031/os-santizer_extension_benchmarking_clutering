~45 s. Section 3 groups prior work into four families. Program-level sanitizers like ASan, MSan, UBSan, plus CFI and FORTIFY, instrument the code and report a fault when it happens, but need recompilation and are too slow for production. Interprocedural tools like SystemSan watch data flowing between programs but only report when the fault occurs. OS-integrated tools like SELinux and seccomp restrict behaviour; they are for mitigation, not testing. Runtime predictive analysis (jPredictor, UFO, ThreadSanitizer) is closest: predict faults from benign runs, but each targets one bug class. OS-Sanitizer generalises this to many classes, system-wide. The enabler is eBPF: verified programs attached at uprobes (user functions), fentry/fexit (kernel functions) and LSM hooks, which share state through eBPF maps, so several small programs can cooperate on one report.
